```{rubric} Features
```
* Read zstd-compressed or uncompressed, optionally sharded zarr v3 arrays from local files straight into GPU memory with KvikIO and decode them with nvCOMP, through {class}`~zarr_kvikio.KvikioCodecPipeline`; read contiguous ranges of sharded 1-D arrays in batches {smaller}`S Dicks`
* Decode everything else on the CPU, with ``kvikio.host_pipeline`` (e.g. zarrs) or zarr's fused pipeline, and copy it to the GPU, so any array can be read {smaller}`S Dicks`
* Select and configure the pipeline through zarr's config alone, like zarrs: ``codec_pipeline.path`` and ``kvikio.*`` keys, or ``ZARR_KVIKIO__*`` environment variables {smaller}`S Dicks`
* Add {func}`~zarr_kvikio.enable` and {func}`zarr_kvikio.dask.enable` to switch GPU reads on in this process or on every Dask worker; only the workers need KvikIO and nvCOMP {smaller}`S Dicks`
* Add {func}`~zarr_kvikio.check` and {func}`~zarr_kvikio.describe` to diagnose the installation and an array's layout {smaller}`S Dicks`
* Add {func}`~zarr_kvikio.convert_array`, {func}`~zarr_kvikio.layout` and {func}`~zarr_kvikio.cpu_pipeline` to rewrite arrays in the layout the GPU reads fastest {smaller}`S Dicks`
* Add {func}`~zarr_kvikio.release_memory` to free nvCOMP's scratch space and the pinned host read buffers {smaller}`S Dicks`
